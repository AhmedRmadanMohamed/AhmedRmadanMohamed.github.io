01 · About

Backend engineering for secure, distributed platforms.

Financial systems, enterprise integration, API security, data access, automated testing, cloud delivery, and production reliability.

Senior Java Backend Engineer and Senior Java Software Engineer with 8+ years of software engineering experience, including 5+ years focused on Java and Spring Boot. I design, build, integrate, and support secure backend systems for financial and enterprise environments.

At Vodafone Egypt, I work on the Vodafone Cash team supporting a platform that serves approximately 25 million users. I develop Java 17 and Spring Boot microservices and REST APIs for digital donation services, QR-code payment journeys, and the integration between Vodafone Shop and Vodafone Cash.

I build event-driven backend flows with Kafka and integrate services with Siebel CRM, Oracle Database, Vodafone Shop, and internal enterprise platforms using Apache Camel where appropriate. I also implement authentication and authorization using Spring Security, JWT, role-based access control, validation, and exception handling.

My responsibilities also include Spring Data JPA and Hibernate persistence, Oracle SQL and PL/SQL optimization, unit and integration testing with JUnit and Mockito, production incident analysis, root-cause analysis, pull-request reviews, and collaboration with cross-functional and DevOps teams delivering through CI/CD pipelines into AWS and Azure environments.
