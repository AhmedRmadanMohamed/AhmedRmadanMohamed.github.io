Project 02 · Backend foundation

E-Commerce Backend — Java 17 and Spring Boot | Ahmed Ramadan Mohamed

An evolving Java and Spring Boot backend foundation for e-commerce domain workflows. The public repository documents the current API areas and the broader domain model while clearly distinguishing implemented functionality from planned work.

Java 17Spring BootMySQLSpring Data JPAHibernateMaven

Overview

The repository establishes a relational domain model covering products, categories, tags, brands, carts, orders, payment-related data structures, users, reviews, and storefront configuration.

Implemented API areas

The README documents endpoints for retrieving distinct application-parameter names, retrieving parameters by name, an application-parameter POST operation, listing brands, and retrieving brands with storefront parameters. A global exception handler and a shared response wrapper are also documented.

Architecture

The documented structure follows a layered approach: REST controllers, services, DTOs and mappers, Spring Data repositories, and MySQL persistence.

Current status and next steps

The repository describes itself as an evolving backend foundation. Its domain model is broader than the current service and controller implementation; it should not be presented as a complete production e-commerce platform. The published roadmap includes additional product, cart, order, review and user use cases, validation, transactions, authentication, tests, and an OpenAPI contract.
