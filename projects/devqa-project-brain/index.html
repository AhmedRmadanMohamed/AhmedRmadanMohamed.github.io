Project 01 · Current milestone: testing and validation

DevQA Project Brain — Spring Boot Repository Intelligence | Ahmed Ramadan Mohamed

DevQA is an IntelliJ IDEA plugin project focused on helping developers understand a Spring Boot repository before code review, changes, or QA handoff. Its current public showcase documents Project Brain, a repository-analysis workspace.

KotlinIntelliJ Platform SDKPSI APIsSwingSpring BootRepository analysis

The problem

Understanding an unfamiliar Spring Boot codebase often means navigating packages, locating application layers, and identifying project resources before meaningful review can begin.

Project Brain approach

The showcase describes a repository scan that presents a project overview, a component inventory, Java type names with package context, and grouped project files inside an IntelliJ IDEA workspace.

  • Project overview with file and Java-type counts
  • Detected Controllers, Services, Repositories, Entities, and DTOs
  • All Classes view with fully qualified type names
  • Project file discovery across source, tests, resources, configuration, SQL, and documentation

Demonstration scope and status

The public showcase includes screenshots from a sample project named HumanResourcesSystem. Its displayed counts are example analysis output, not benchmarks or fixed product limits. The current milestone is testing and validation; an “Analysis complete” state means the scan finished and does not mean that tests, quality checks, or security reviews passed.

Implementation direction

The public product documentation identifies Kotlin, IntelliJ Platform SDK, IntelliJ PSI APIs, and Swing/IntelliJ UI components as the implementation direction. The production source code is maintained privately; this page describes only the public showcase.
