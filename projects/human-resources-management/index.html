Project 03 · HR management backend

Human Resources Management Backend — Spring Boot REST API | Ahmed Ramadan Mohamed

A Java and Spring Boot REST backend organized around recruitment and workforce-reference workflows, with PostgreSQL persistence and integrations for verification, email, and image handling.

Java 11Spring BootPostgreSQLSpring Data JPAREST APIsSwagger

Overview

The public repository documents backend workflows for job seekers, employers, job listings, job positions, workplaces, work times, cities, approval operations, and image uploads.

Documented capabilities

  • Job-seeker and employer registration and lookup
  • Job creation, visibility changes, approval queries, and date-based filtering
  • Job-position, city, workplace, and work-time reference endpoints
  • Account activation and approval operations
  • Identity-check and email-verification adapters
  • Cloudinary-backed image upload adapter

Architecture and technology

The documented architecture connects API controllers to business services and managers, external verification/email/image adapters, Spring Data DAOs, and PostgreSQL persistence. The repository lists Java 11, Spring Boot, Spring Data JPA, and Swagger-based API documentation support.

Repository guidance

The project README points to the detailed API notes in HRMS_Backend-master/APIDocumentation.md. Configuration examples use placeholders; credentials should remain outside version control. The repository notes that generated build output should be recreated from source rather than maintained manually.
